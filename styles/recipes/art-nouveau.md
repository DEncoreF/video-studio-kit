## 一句話
植物曲線與藤蔓從畫面邊緣生長、纏繞成框，文字被優雅的曲線包圍。

## 需要提供
- 片長；主張；適合人文、教育、永續、ESG 主題

## 方向
- 曲線全部「生長」出來（由一端畫到另一端），不跳出
- 大地色系、淡綠與赭色；襯線字
- 禁用：直角網格、霓虹、硬切、粗黑框

## 結構
1. 兩條藤蔓從左下與右下生長，在中央交會成拱形 → Logo 浮現
2. 藤蔓長出葉片與花苞，框住主張
3. 花苞綻開成數字的背景圓
4. 藤蔓收成一個圓形花環，中間是 Logo

## 製作
- SVG path 的 stroke-dashoffset 生長；葉片用小 path 依序放大
- 緩動：slow、帶一點延遲錯開（stagger 0.2）
- 字：Noto Serif TC 700／900

## 注意
- 曲線要有粗細變化才像手繪，可疊兩條不同粗細的 path
- 曲線不要穿過文字

## 參數
- 底 #efe7d4、墨 #2f3b2a、綠 #7a8f5a、赭 #c58b5b
- 緩動：slow
