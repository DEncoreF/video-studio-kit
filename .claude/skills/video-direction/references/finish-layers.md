# 質感層：驚艷從使用者的參考長出來

**用在**：使用者要「驚艷」「專業」的片子，第 3 步找參考、第 4 步出三個方向，以及每一版草稿動手之前（video-motion-craft 第 1 步會指回這裡）。

背景：film E（2026-10-28～29）自己發明了一套新外觀，35 版量測都過，使用者：「有點怪 沒有讓我很驚艷 不論是腳本還是過場運鏡動態特效好像都不夠」。接著說明：「硬切也是能驚艷我啊 主要是整體質感問題，跟你組件、字體、顏色、動態效果、過場整體組成的感覺，我應該有傳給你的 reference部分也是用硬切，而且其實主角根據情境轉換狀態及性質我也傳給你過，不見得是都有不間斷都是同一個型態的主角」。

## 1. 起點：使用者給過的參考與核可的元件

不要另外發明一套外觀。先從下面這些開始，新找的參考是補充，不是取代：

| 來源 | 在哪 | 借什麼 |
|---|---|---|
| Apple Creator Studio、Google Vids、Raycast | 片子在 `~/.video-studio/rulers/`；量到的數字在 內部研究筆記 | 字變成元件、剪點對拍、一個容器一路變形 |
| Prompt Motion showreel | 內部研究筆記 | 每拍新構圖、每個字自己的進場、條狀掃過與甩鏡交棒、停留時元件繼續長 |
| Linear Agent、Apple Don't Blink | `verbs-references.md` | 斜放介面慢推、粗細對比收尾；重點字滿版反轉當標點 |
| 核可的元件組 | studio 品牌套件裡核可過的元件 CSS | 卡片、晶片、輸入框、標註的圓角、陰影、字級 |

其他品牌沒有核可的元件組時，照實機截圖重建（visual-verbs.md 的 `ui` 列），核可後放進 `brand-kits/<kit>/ui/`。

元件組借的是元件，不是整套外觀：v2 的紫色漸層舞台、卡片的紫色光、EB Garamond 大字是 D 片的選擇，不是每支片的預設。底色、字體、強調色每支片照 [frame-spec.md](frame-spec.md) 寫成數字，品牌紫當唯一的強調色。

## 2. 五層逐拍對尺

每一拍寫一列進 `direction/finish.md`，每一格都要指得出對到哪件參考的哪一刻：

| 拍 | 元件 | 字體 | 顏色 | 動態效果 | 過場組成 | 對到的參考（片名＋秒數） |
|---|---|---|---|---|---|---|

- **元件**：用核可的元件組重建，不貼截圖、不另畫一套。
- **字體**：靠字重與大小對比做層級；字族從尺選（frame-spec.md §1）。大字只在畫面說不出來時才出現，不是每一拍都要有（script-craft.md §6）。
- **顏色**：品牌色當唯一的強調色、有一個意義，最多換一階明度；不用參考片的彩虹底，也不用滿版漸層當預設（frame-spec.md）。
- **動態效果**：每個字有自己的進場（帶模糊甩入、落下、追蹤進場、殘影對位）；停留時有意義的小事件可以繼續長（計數跳到值、長條長、游標閃），不做無目的的漂移或晃動。
- **過場組成**：硬切、甩鏡、條狀掃過、色塊淹沒都可以，打在拍上，下一格是新構圖；拍與拍之間唯一不用的是溶接（新舊半透明疊在一起，transitions.md）。主角可以隨情境換狀態與性質，不必從頭到尾同一個型態。

## 3. 整支之前先做最難的鏡頭（質感試片）

節奏單寫完之後（SKILL.md 第 5 步），先做全片最難的那一鏡，用最終解析度、字型、顏色做到位（huashu-motion、motionmaxxing、Cinetic 都把這一步寫成流程）：挑最有代表性的 2–3 拍（含一個交棒和驚艷的那一刻），放 `videos/<專案>/tests/_finish-<片>` 做 10–12 秒。和尺並排比：`node <tool>/scripts/hf.mjs snapshot <試片> --at … --against <尺.mp4>`，五層逐一寫出差距（寫進試片的 `NOTES.md`）。五層都說得出「和尺同一個等級」才排整支；說不出就改試片，不要往下做。試片給使用者看之前照樣過 video-draft-review 的試片量測。第 3 步概念關寫的那一刻就在這一支裡。
