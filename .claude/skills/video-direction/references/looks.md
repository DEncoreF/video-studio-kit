# 畫面的光與材質：深色、半寫實、借尺

**用在**：第 4 步出方向、出深色版、寫 `frame.md` 的時候（frame.md 要寫哪些數字與禁用清單在 [frame-spec.md](frame-spec.md)）。審片時的對應檢查在 video-draft-review 的 `references/failure-list.md`（「暗部吃掉主體」「假寫實的 3D 介面」「字上有反光」）；這裡是做的時候的規則。

## 1. 深色：黑只當背景

使用者 2026-10-25 看 film C 深色草稿 2（05 版本那一拍）：「你有些地方陰影都打得太多了 根本看不到其他地方」。頁面上半被暗部吃掉、上一版幾乎看不見、畫面上半一片黑。這一版過了審片關卡，審片者也說可以送：規格把參考片「≥ 70% 近黑、亮區 ≤ 25%」的數字用在了內容上。

- **黑是背景，不是內容**：這一拍在講的東西（整頁、兩版、整張圖、整個面板）要整個看得到。不能被光切掉一半；物件內部不做漸暗、不做暗角。
- **焦點靠亮度差一階，不靠落進黑**：焦點 100%，同一個物件的其他部分 75–85%，旁邊的上下文（上一版、別的條款）55–65%。字都要讀得出來。
- **標題放在背景的黑上**：構圖時就留出標題的位置，主體擺在標題區之外。不在紙或面板上墊一層暗紗或漸層讓標題可讀。標題在畫面上時，紙退到約 80%（60–70% 看起來像髒的灰）。
- **構圖要裝滿**：主體佔畫面的主要區域，不留半個畫面的空黑。推近時主體的邊可以出框，但不能被暗部吃掉。
- **面積的數字只管背景**：近黑、亮區這類從參考片量來的比例，只約束主體以外的地方，主體本身不受面積限制。
- **從光重新設計，不是換底色**：淺色版換成深底色只能當對照（使用者：「不要作比較而是針對深色去做整體的設計」）。暗場的語法與數字見 內部研究筆記。
- **產品要看得到**（所有風格都適用，不只深色）：結尾的機器正面要被照亮，標誌讀得清楚。結尾怎麼排見 script-craft.md §7。
- 審片時每一拍多問一句：「這一拍在講的東西，整個看得到嗎？」

## 2. 半寫實與玻璃

film C 的質感測試（2026-10-24）：照使用者的提議，把整個視窗做成不透明的紫色厚玻璃，做了 3 輪才發現連 Cycles 算出來都像「印上去的塑膠板」。兩支尺其實都沒這樣做：Copilot 的介面是平的，Outlook 的玻璃只用在道具上。

- **採用新做法前，先回頭對照尺**：尺上沒有的做法，先找出它從哪來、尺為什麼沒用，再決定要不要做。
- **玻璃要透得過去**：約 35% 不透明，後面的紙和字看得到、會折射；只在字的正下方墊霧面。字上不能有反光。
- **「假」先分清是算圖還是設計**：先做 A（Cycles 物理正確）／B／C 的對照，再決定改哪一邊。

## 3. 借尺的品質，不搬尺的外觀

使用者 2026-10-23 看 film C 草稿 4（照抄 oner 的深色 HUD 和紫點）：「視覺主體不一定要是球，要參考的是流暢度」「要過我這關很難」。

- 尺是拿來量品質的（流暢度、層級、停留），不是拿來搬外觀的。照抄一支參考片的配色與主角，不算一個方向。
- 風格要依這支片的流程想（使用者：「我需要你根據這個流程想風格」）。每個方向寫明借了尺的哪一條（SKILL.md 第 4 步），不是借了哪個畫面。
