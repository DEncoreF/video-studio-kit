# 功能畫面研發：動詞 → 型態

用在第 3 步寫腳本時：每個功能、每個主張，先研發「最好的呈現方式」，再動手做。Buck 做 Surface 發表片時，花大量時間在設計與研發上，為每個功能找最好的呈現方式。semantic-type 對標題就是這樣做；這裡擴大到每個功能和每次變形。

背景：
- F 片 草稿 3–4 的變形是「形狀換形狀」（紙 → 卡片 → 線），順，但沒有理由。
- 使用者要的是「主角可以變形、根據動作轉換型態，像是寄信出去可以把文件視窗折成紙飛機」（2026-10-24）。

## 做法（寫進 direction/visual-verbs.md）

每一拍一列：

| 拍 | 動詞 | 三個真實的畫面比喻 | 選哪個、為什麼 | 另外兩個為什麼輸 |
|---|---|---|---|---|

1. **動詞**：這一拍發生的動作（寄出、拆開、比對、排期程、蓋章、闔上…）。
2. **三個真實比喻**：人或東西在現實裡真的會這樣動，一般人一秒內認得出來。從職業、文具、機構、材質去想，例如寄出 → 紙飛機、信封封口、郵筒；比對 → 複寫紙錯位、燈箱疊圖、放大鏡。
3. **選最直接的**：不用解釋、不用加字就成立；輸的理由要具體（太慢、要加道具、和品牌衝突、太抽象）。
4. 變完的樣子，就是那個動作的結果。

## 呈現層：先用介面互動演，不重演真實操作

使用者 2026-10-24：「動作不用真實場景，建議用互動，像是手機螢幕打字對話，不要用真實打字畫面呈現」。研究也支持這點：Apple 把 UI 從螢幕裡「拿出來」變成實物，Linear 只演「空白輸入框 → 一句話 → 結果流出來」，Notion 用一架紙飛機代表寄信，三支都不拍人怎麼操作。

每一拍選一種呈現層，寫進 script.json 的 `layer`：

| 呈現層 | 什麼時候用 | 怎麼演 |
|---|---|---|
| **介面互動** `ui`（預設） | 大部分的拍 | 動作用介面自己的反應呈現：通知卡展開、檔案晶片滑進輸入框、按下 →「✓ 已寄出」膠囊、訊息泡泡送出、AI 回覆一段段流出來。元件依實機截圖重建（排版、欄位、文案照實機），不直接貼截圖；介面語言照這支片的決定（使用者：「你參考排版就好，元件重產」「參考真實元件，並重建成影片適合的應用方式」） |
| **材質變形** `material` | 主角拍，全片最多 3 個 | 主角換成實物的型態：摺成紙飛機、翻牌、複寫紙錯開、捲軸攤開（做法與時間見 video-motion-craft 的 [material-morphs.md](../../video-motion-craft/references/material-morphs.md)） |
| **實景** `real` | 只在頭尾當錨點 | 真實的桌面、筆電、手機（例如開蓋、闔蓋）；中間要回到實景時，讓 UI 從螢幕拿出來，不讓鏡頭整個鑽進螢幕 |

- **打字**：只逐字打前幾個字（約 12 字以內），接著整句出現，或像訊息一樣送出。不拍鍵盤、不拍手、不逐字打完長句。
- **不重演**：滑鼠移過去點、捲動找段落、手指敲鍵盤，這些操作過程都省掉，直接演結果。
- script-lint 會檢查：實景不在頭尾、材質變形超過 3 個或不在主角拍、逐字打超過 12 字。

## 主角變形的規則

主角變形是一種方法，一鏡到底或硬切的片子都可以用；主角也可以隨情境換狀態與性質，不必一路同一個型態（finish-layers.md §2）。用了變形時：

- **每個變形都要有動詞**：沒有動詞的變形拿掉，或改成鏡頭運動。
- **主角有一個不變的記號**（選了一鏡到底時必要，其他形式選用）：例如紙的一角帶紫色摺角、固定的厚度與陰影。變成卡片、紙卷、紙飛機都認得出來。
- **形狀押韻**：前後呼應的形狀讓轉場自然，例如游標箭頭 ↔ 紙飛機輪廓、視窗闔上 ↔ 筆電闔上。至少安排一組首尾押韻。
- **大小交錯**：主角變形 ≤ 3 個，放在主角拍；其餘用小變形或鏡頭帶過。
- **物理感**：蓄力（反方向先動一點）→ 擠壓 → 過頭 → 回到位置；材質要有對應的聲音（紙、空氣、木頭），不要純音。
- **語意不能錯**：例如回信本來就要寄給對方，紙飛機飛出去是對的；「資料不外流」說的是 AI 處理留在本機，所以要演處理的光收回機器，不是演信飛不出去。

## 範例：F 片 的變形鏈（2026-10-24 提案）

| 拍 | 動詞 | 型態 |
|---|---|---|
| 收信 | 點開 | 通知卡展開成整封信，附檔浮起 |
| 01 | 送出 | 附檔滑進輸入框；按下 Enter，那句話化成光把紙吸進去 |
| 02 | 拆開 | 整頁被裁成一條條條款，落進貼標籤的分類盤 |
| 04 | 改寫 | 「九十」像機場翻牌一樣翻成「四十五」；出處像書籤緞帶從頁緣抽出 |
| 05 | 比對 | 複寫紙上下兩層錯開，對不上的字發光 |
| 06 | 排期程 | 頁面捲成紙卷，攤開成甘特圖，保固那一列攤到盡頭是「?」 |
| 由您決定 | 蓋章 | 游標變成印章，蓋下去的地方紫色草稿變成墨色正文 |
| 回覆 | 寄出 | 文件視窗折成紙飛機，飛進回覆視窗 |
| 結尾 | 闔上 | 寄件視窗折起，筆電用同一個動作闔上 |
