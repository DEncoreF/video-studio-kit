# 案例、反例與手法家族

## 一、核可案例

### 產品片（2026-10-21 定版）

八個標題都在深色產品頁版面上：標題襯線粗體約 120px，上方部門標籤、下方說明與「情境示意」章，右邊是介面面板。「三個動作」是事後整理的候選，用來示範怎麼挑。程式片段用 `lib`（`lib/semantic-type.js`）改寫，`at` 是動作起點，`cue` 是關鍵瞬間；原片在圖庫標籤 `semantic-type`、`內部金標`，可以只播那一段。

#### 資料不出門：門甩上鎖住
- 重點字：門。三個動作：門甩上鎖住／資料撞牆彈回／保險箱轉盤上鎖 → **門**：字裡本來就有門，不用加道具。
- 做法：「出」先往外傾（`x: 18, skewX: -5`，想出去）；「門」用 `lib.halves(門, {axis: "x"})` 切成兩扇門板，以外側為軸 `rotationY: ±62°` 開著，在 `cue` 前 0.2 秒 `power3.in` 甩上；門板合上那一格整個字 x 抖一下（−5 → 4 → 0，約 0.17 秒），「出」被 `elastic.out` 推回原位。
- 音效：click＋impact（門板的重量）。專做的門閂音色試過，使用者覺得這版較好。
- 學到：用字本身當道具；動作只有「關上」一件事；結尾兩扇門板與原字完全重疊。

#### 7 台：計數器數到 7
- 三個動作：計數器從 1 捲到 7／七台機器排成一排／七個點依序亮起 → **計數器**：數量本身就是重點，「數」最直接，不用加圖形。
- 做法：`lib.roll(數字元素, at, {from: 1, to: 7, dur: 0.84})`（1em 高的遮罩、每格 back 曲線卡到位、`power1.in` 越數越快）；到 7 之後「台」`scale 1.25 → 1` 落下。`semtype.json` 寫 `transient_text: "123456"`。
- 音效：機械計數輪（counter），每格一聲。

#### 文件審閱：放大鏡停在「審」
- 重點字：審。三個動作：放大鏡掃過內文、停在審／紅筆圈注／翻頁 → **放大鏡**：「審閱」就是逐字細看。
- 做法：標題照常出現後，一個不透明鏡片沿標題滑過：鏡片裡放同一行字的 1.3 倍複本，位移與鏡片反向（只看得到放大後的字）；路徑＝左進 → 滑行 → 停在第三個字「審」0.35 秒 → 滑出。握把朝左下，不壓到下方文案；只在標題帶內移動。
- 音效：對焦＋玻璃清響（lens）。
- 學到：停在重點字上就是把它演出來；鏡內只有放大的同一行字，沒有新資訊。

#### 算力管控：量表填到上限停住（結尾＝語意）
- 三個動作：量表填到上限停住／水龍頭被關小／限速指針停在紅線 → **量表**：同一頁的介面就是用量量表，語言一致。
- 做法：`const f = lib.outlineFill(title, {steps: 9})`（空心字＋實心複本，9 格階梯式往上，不是連續液體）；旁邊細刻度尺、一條跟著水位走的細線；上限虛線放在 `f.m()` 量到的墨跡高度的 76%；`f.set(k * 0.76)` 在 0.8 秒內填到上限、上限線閃一下；刻度與細線退場；**停在上限，不補滿**。
- 音效：segtick 每格一聲、音高往上爬，到位一聲。
- 學到：第一版放了 76.0% 讀數與標籤被否決（不加資訊）；QA 時補滿成實心也被否決（結尾狀態就是語意，`semtype.json` 要記 `end: "meaning"`）。

#### 教學備課：粉筆寫在黑板上
- 三個動作：老師用粉筆寫黑板／翻開課本／舉手發問 → **寫黑板**：最能代表「教學」的職業動作。
- 做法：字後方一條淡淡的擦過的黑板帶（框內）；字改成粉筆色並套 `url(#st-chalk)`（`lib.filters()`）；`lib.writeOn(tl, title, chars, at, {per: 0.32, tip})` 讓粉筆頭沿每個字 zigzag、由左到右揭露；`lib.particles` 讓粉筆灰從筆尖往下掉；寫完畫一條略斜的粉筆底線。粉筆質感是結尾的一部分（結尾＝語意，要先問）。
- 音效：slide（顆粒摩擦）。專做的粉筆音色試過，使用者覺得這版較好。
- 學到：第一版是發光筆尖來回寫，不像老師——職業動作要像真的。

#### 在地端：從雲端落到機房地板
- 三個動作：雲裡的點凝結成字、落到地板／一條網路線從雲接到機櫃／機櫃燈號依序亮 → **落地**：重力＋地板就是「在這裡」。
- 做法：上方一片細點雲；三個字依序從點雲凝結（模糊 12px → 0）、`power2.in` 落下 0.36 秒，落在半拍；落地 `scaleY .9 / scaleX 1.05` 再 `elastic.out` 回彈（`lib.land`）；接觸陰影隨落下放大；揚塵＝柔軟塵團（先快後慢、往兩側）＋少量碎粒拋物線（`lib.particles`）；鏡頭隨每次落地震一下（`lib.thud`）；點雲隨字離開變稀。原片標題置中、上方是空的，所以能從高處落下；在有鄰近元素的版面要從框內短距離落下。
- 音效：柔和下沉 whoosh＋顆粒塵（dust），落地對半拍。
- 學到：技術名詞演技術意義（雲 → 自己的地板）；重量是好幾個線索同時發生。

#### Agent 治理：印章落下，Agent 才被拉齊
- 重點字：治理（原因），Agent（結果）。三個動作：印章蓋下、散亂的字被拉齊／一條規範線把字對齊／欄杆把字圍起來 → **蓋章＋拉齊**：先有治理，才有秩序。
- 做法：Agent 五個字母先模糊、漂浮、亂轉（`lib.rng` 固定種子，留在標題欄內）；`cue` 時「治理」`lib.stamp`（`scale 1.6 → 1`、`power4.out` 0.22 秒）＋一圈震波；三條導線從治理往左長出，位置是 `lib.metrics()` 量到的大寫高、x 高、基線；字母由近到遠一個個被拉齊，每個字母的框線貼著量到的墨跡閃一下；最後留一條淡基線。
- 音效：stamp（橡皮章）＋輕 impact。
- 學到：第一版每個字（含治理）一起被拉齊、框線用 em 方框估，被指出「框框好像沒有對到字」——要量真實墨跡，並讓重點字成為原因。

#### 成長計畫：從種子長出來
- 片中核可，但之後整理範例時被標為「不喜歡」：不要當範本。只留著看種子＋長出的做法。
- 三個動作：種子發芽長出字／澆水／一階階往上 → **發芽**：從小到大、由下往上，一眼就懂。
- 做法：每個字下方先 pop 出一顆發光種子（`back.out(3)`）；字以底部為軸 `scaleY 0.02 → 1`、`scaleX 0.55 → 1`（`elastic.out`），顏色由輔助色轉白；種子縮小淡出；字與字錯開 0.15 秒。
- 音效：pop（種子冒出）。

### 一支 AI 平台的一鏡到底產品片（2026-10-22）

一支 16 秒的一鏡到底產品片：整個畫面由 `render(t)` 依時間畫出，鏡頭一直在動；一顆代表「一次呼叫」的光點從輸入框射出、在分派節點選路、掉進額度條、寫下稽核紀錄。大字是襯線粗體 160px，放在左下，下面一行說明字幕，四周是 HUD（專案名、「情境示意」章、時間碼、幀數、章節）。五個大字都在凍結世界的測試複本裡做（SKILL.md 第 2 步、`semtype.mjs copy`）。使用者看過片段後說「五個效果都可以，搬進正片並輸出 v5。」，看過 v5 後說「可以了」。五個效果放在片子裡同一個 `typefx.js`。

五個效果的共通做法：
- **純函式**：每個效果是 `make(title, key, lib)`，回傳 `draw(t)`。`t` 是片內時間，每個樣式只由 `t` 決定；動作演完就清掉自己設的 inline 樣式，結尾就是原版面。測試複本和正片的 `render(t)` 呼叫同一個函式，搬進正片一行都不用改。退場由正片統一處理：整個詞一起往上淡出。
- **和世界同一拍**：關鍵瞬間對到片中同時發生的事件：送出 2.25 秒、選中地端 4.25 秒、第 8 格亮起 7.0 秒、蓋 ✓ 9.6 秒。字不另外演一齣戲，而是把畫面正在發生的事說出來。
- **框內遮罩**：動作中用 `clipPath: inset(-0.13em)` 把字限制在自己的框內，演完就清掉。

#### 一次呼叫：軌跡拉出「一」那一橫
- 重點字：一。三個動作：光點射出的軌跡就是「一」那一橫／字跟著射出被拉長／每個字響一聲脈衝 → **軌跡**：「一」本來就是一條線，和光點射出的軌跡是同一件事。被拉長的字容易糊；脈衝像訊號燈，不像呼叫。
- 做法：關鍵瞬間是送出（2.25 秒）。「一」用 `clipPath` 由左往右揭露（`outExpo`，0.22 秒），先是光點的品牌色，再轉回字色。前緣有一顆柔光頭，和光點拖出的彗星是同一種光。其餘三個字從左邊 0.25em、模糊 6px 的位置依序滑進來，每字間隔 0.05 秒。
- 音效：click（送出：光點被壓縮後彈出）＋往右的 whoosh（劃開空氣，和「一」同時拉出）。
- 學到：片中已有的視覺元素和字的某一筆剛好同形時，就讓那一筆成為那個元素。

#### 自動分派：字沿地端路線滑進定位
- 重點字：派。三個動作：四個字沿著和地端路線同一條 S 形曲線滑進定位／「分」字切成兩半／三次掃描閃光 → **沿路線**：被派到那條路上最直接。切成兩半像分裂，不像分派；掃描閃光和路線上的掃描重複。
- 做法：每個字沿同一條三次貝茲曲線（先往右滑出，再往下彎進自己的位置，和地端路線同形）移動 0.46 秒，後面拖著兩個品牌色殘影。「派」帶頭、「自」最後，字與字間隔 0.07 秒；整個詞在光點走上地端路線那一拍（4.25 秒）完成。
- 音效：lock（地端被選中，模組卡入，4.13 秒）＋current（字沿路線滑進、光點走上地端，像乾淨的電流沿線移動，從 4.25 秒開始）。
- 學到：第一版照閱讀順序讓「自」先到，後面的字都要經過前面已經停好的字，殘影也有三個，中途四個字疊成一團、讀不出來。改成最遠的字（派）先走，字像列車沿路線拉開，任何一格都分得開。檢查全部通過也抓不到這個問題，是看 `check/sheet.jpg` 才發現的。

#### 計入額度：字一個一個掉進定位，像量表一格一格亮起
- 重點字：計入。三個動作：字一個一個由上往下掉進定位，每落一字量表亮一格／空心字填到上限／數字計數器 → **逐字掉進來**：「計入」就是一格一格算進去。空心字填到上限在「算力管控」用過，同一套手法不重複；計數器會多出數字，等於加資訊。
- 做法：每個字從上方 0.62em 處以淡的品牌色、模糊 5px 的狀態用 `in2` 落下（0.17 秒），字與字間隔 0.15 秒。落定時有一個會衰減的壓扁回彈（阻尼振盪），顏色由淡的品牌色轉回字色，像量表格亮起後穩定下來。最後一個字「度」落在光點點亮第 8 格的同一拍（7.0 秒）。
- 音效：segtick ×4，音高 C → D → E → G 往上爬：前三聲對應三個字落下，G 和第 8 格同拍；最後一拍再墊一聲很輕的 thunk 表現重量。
- 學到：片中已有的計量聲（第 8 格的 G）可以往前延伸成字的節奏，讓聲音和畫面一起爬到同一個點。

#### 留下紀錄：熱感印表機逐行印出
- 重點字：紀錄。三個動作：熱感印表機逐行印出／蓋章／先畫一條底線 → **列印**：和畫面上光點正在寫的紀錄是同一件事。蓋章和片中蓋 ✓ 重複；底線太弱。
- 做法：每個字在一條發光的熱印頭下一列一列印出，以 4px 為一列階梯式前進，不是連續揭露。剛印好的列帶著淡淡的網點（`repeating-linear-gradient` 遮罩），0.2 秒後變成實心。由左到右每字印 0.32 秒，「錄」在蓋 ✓ 那一拍（9.6 秒）印完。熱印頭的寬度貼著 `lib.metrics()` 量到的每個字的墨跡。
- 音效：printer（均勻的細碎聲，1.4 秒）＋stamp（「錄」印完、✓ 蓋上）。
- 學到：畫面已經在做的動作（蓋 ✓）不要讓字再做一次，改挑和它相鄰的那一步（印出來）。

#### 一次呼叫，全程都管好（結尾）：沿用開頭的「一」，一道光掃過全程
- 重點字：全程。三個動作：第一行沿用「一」、第二行被一道光由左到右掃過後定住／第二行逐字蓋章／整句一起淡入 → **光掃**：第一行和開頭用同一個「一」，前後呼應；光從頭掃到尾就是「全程」。逐字蓋章是加戲；整句淡入沒有呼應。
- 做法：兩行各包成一個區塊，行框和原本的 `<br>` 相同。第一行重用「一次呼叫」的筆畫動作，在光掃前 0.45 秒開始。第二行用 `clipPath` 跟著一條 0.3em 寬、模糊 4px 的光帶由左到右揭露（0.6 秒，`inOut2`，速度和鏡頭拉遠一致），光帶高度貼著量到的墨跡。
- 音效：whoosh（柔和的空氣跟著光走，音量 0.3）。
- 學到：收尾要穩、可讀；重複開頭的同一個動作，比新的花樣更有收束感。

## 二、反例（被否決的版本）

| 版本 | 做了什麼 | 使用者原話／問題 | 規則 |
|---|---|---|---|
| 算力管控 v1 | 量表旁加 76.0% 讀數與標籤 | 「就有點過頭，因為數字本身對於標題沒有幫助」 | 不加資訊 |
| 算力管控 QA 版 | 停在上限後再補滿成實心 | 「改回原本：停在上限、不補滿」 | 結尾＝語意時保留，先問 |
| Agent 治理 v1 | 所有字一起被拉齊；框線用 em 方框 | 「框框好像沒有對到字」 | 量真實墨跡；重點字是原因 |
| 教學備課 v1 | 發光筆尖來回寫 | 不像老師 | 職業動作要像真的 |
| 在地端（字面） | 字沉進地底／掉到地上 | 「這邊在地端是指技術上面的」 | 技術名詞演技術意義 |
| 音效 | 寫實門閂、專用粉筆音色；玻璃泛音；8-bit | 「前一版更好」「有玻璃不代表有質感」「太可愛了，不專業」 | 質感＝層次與節制 |
| 推鏡 | 為了避開標題，推近的點偏離結果 | 「效果及目的都有點怪」 | 說不出在演什麼就不動 |
| 片頭被當成雷達 | 環＋掃描光束＋目標點 | 「有點太複雜了」——片頭原意是開機 | 先確認原本要表達什麼 |
| 自動分派 v1（一鏡到底） | 照閱讀順序「自」先到，四個字沿同一條路線依序滑進，各拖三個殘影 | 中途疊成一團、讀不出來；檢查全部通過，是自己看 `sheet.jpg` 發現的 | 中途不能糊成一團：沿同一條路移動時，最遠的字先走 |

外部作品裡也有同樣的錯：一支太陽光子的影片在「AGAIN」旁加了反彈次數、深度、溫度的計數器（多加資訊）；一支示範 BOUNCE 的影片在字旁寫了手寫註解。

## 三、手法家族（外部參考，只取手法）

每個家族：字義是什麼時用、動作、做法要點。參考都記在 `refs.mjs`（標籤 `semantic-type`），在圖庫可以只播那一段。外部作品常常跑出框、全畫面、或一直循環——照我們的規則收斂後再用。

| 字義 | 動作 | 做法要點 | 參考 |
|---|---|---|---|
| 重、落地、在這裡 | 從框內短距離落下，壓扁回彈，地板受力，揚塵 | `lib.land`＋`lib.thud`＋`lib.particles`；壓扁 scaleY 不低於 0.5 | hanifproduktif〈WEIGHT〉、zheke〈SQUASH〉、Ji Lee〈Gravity〉 |
| 減少、刪除、拿掉 | 按下開關，被拿掉的字自己掉出 | 因果：先有按下（原因），字母沿弧線掉落（結果）；保留下來的字回到原位 | ultimaxbt〈Reduce Motion〉 |
| 失去、遺忘、消失 | 字從某一側開始變淡 | 逐字 opacity 遞減或 mask 漸層；只淡最後一個字，留住可讀性（結尾＝語意，先問） | Saul Bass〈Bunny Lake Is Missing〉、Ji Lee〈Memory〉 |
| 逃走、抓不住 | 被點名的那個字側移、變糊、變淡，其他字不動 | 只動一個字；動作很小（半個字寬） | Kuntzel + Deygas〈Catch Me If You Can〉 |
| 分裂、切開、分流 | 沿一條線切開、兩半錯開 | `lib.halves` 上下或斜切；錯開約一個筆畫寬；斜線角度避開水平筆畫 | Saul Bass〈Psycho〉、prasenx〈CUT.〉、Codrops〈Sliced Text〉 |
| 升起、開始、明天 | 從一條基線（地平線）下面升上來 | `overflow: hidden` 容器，下緣對齊基線，y 由 100% 到 0 | samaote〈tomorrow〉、Ji Lee〈Horizon〉 |
| 秩序、對齊、整理 | 散亂的字一次被拉正到同一條基線 | 隨機 rotation／y（固定種子）→ 一個 `back.out` 同時歸零；導線用量到的基線 | souravbhar871〈straight〉、blushpetal795〈complexity → clarity〉 |
| 承重、支撐、等待 | 字是受力的構件：掛在線下把線壓彎，或立起來當柱子 | 一個 sag 變數同時驅動線的彎曲與字的位置；中文可直排 | gdgtify〈WAITING／VOICE〉 |
| 辨認、未知 → 認得 | 筆畫亂序一片片出現，最後一筆落下才讀得出 | 中文天生是筆畫組成；壓到 1–2 秒 | Richard Greenberg〈Alien〉 |
| 材質即意思 | 字本身由那個材質構成（指紋紋路、液體） | 文字當遮罩、補間紋理參數；中文筆畫密時紋理要放大 | abhinayguptha〈WHORL〉、Animography〈Colloid〉 |
| 格式、轉換 | 原始語法被渲染成排好的樣子 | 兩層疊在同一位置，打字 → 符號碎掉 → crossfade | HO_BA〈markdown〉 |
| 爆、破、縮 | 戳破只剩放射線；縮成一點消失 | 結尾是消失（結尾＝語意，先問） | Animography〈Chubs POP!／SHRINK〉 |
