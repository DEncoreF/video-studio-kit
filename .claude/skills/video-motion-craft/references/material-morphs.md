# 材質變形：實物怎麼動、怎麼做

**用在**：主角拍的材質變形（`layer: "material"`，全片最多 3 個）要做出來的時候：摺成紙飛機、翻牌、燈箱／複寫紙、捲起再攤開。選哪個動詞、哪個比喻在規劃時由 video-direction 的 `references/visual-verbs.md` 決定；這裡是做法與時間。變形完的停留照 [reads-and-beat.md](reads-and-beat.md) §1 與 SKILL.md 的數字表（`library/rules/motion.json`）。

## 實物怎麼動、怎麼做（實測，2026-10-24）

14 支片用 /watch 逐格量（實物 1 支＋動態設計或 UI 1–3 支）。原始數字與網址在 內部研究筆記。做法都以 render(t) 只看時間為前提，可以用 three.js，不用 CSS 假 3D。

| 變形 | 實物量到的 | 做法 | 時間 | 不要 |
|---|---|---|---|---|
| **摺成紙飛機**（寄出） | 真紙對摺約 0.4 秒；摺痕先是帶亮帶的圓弧，再壓成銳線 | three.js 摺紙網格，視窗畫面貼在紙上；每條摺線是 3–4 段的帶狀區，彎曲半徑隨時間收到 0 | 4 摺各 0.3–0.35 秒 → 停 0.3 秒 → 往後 0.15 秒蓄力 → 側傾 15–25° 加速飛出 | 用溶解代替摺；飛向觀眾 |
| **翻牌**（改寫數字） | 實速一字 78 毫秒；單片下落 35–40 毫秒，重力加速、硬停，回彈最多 1 格 | 每格的上半片繞鉸鏈轉 0→−180°，正面舊字上半、背面新字下半；下落片亮度 ∝ \|cos θ\|，舊字下半蓋投影 | 每步約 90 毫秒、格與格錯開約 70 毫秒，經過 3–5 個相關數字；最後一步 130 毫秒加 1 格回彈；總長 ≤ 0.8 秒，停 ≥ 1.5 秒 | 中間閃亂碼；空白格看起來像故障 |
| **燈箱／複寫紙**（比對） | 兩層貼合時邊緣銳利，上層一離開就糊、變暗：層距＝模糊量；掀起的紙成弧、在下層投柔影 | 兩張對齊的平面，上層抬起並橫移 6–10% 頁寬；模糊和影子都綁層距；兩層染色後相乘，差異用真實文件的 diff 遮罩 | 錯開 0.5–0.7 秒緩入緩出 → 0.3 秒內差異亮起 → 停 ≥ 1.5 秒 | 紅綠配色（沿用片子自己的顏色語意）；硬切出結果；亮起的不是真的差異 |
| **捲起再攤開**（排期程） | 真卷軸起步約 0.7 秒較慢、之後近等速；軸邊轉邊移、不打滑；靠軸的紙抬起約一個軸徑 | vertex shader 把紙彎到螺線上，捲越多軸越粗；明暗由彎曲法線算圓柱漸層，交接處暗槽、軸下接觸陰影；軸的轉角＝位移÷半徑 | 捲起 0.8–1.0 秒 → 停 0.3 秒（看不到紙面時換內容）→ 展開 1.2–1.5 秒、最後 20% 放慢 → 停 ≥ 1.5 秒 | 羊皮紙、火漆（像古代詔書）；內容用淡入，要靠展開露出 |

聲音：只有翻牌量得到（每片一聲、衰減 < 40 毫秒、最後一聲大一點）；摺紙、燈箱、卷軸都沒找到乾淨的實錄，要另找或自己錄紙的聲音。
