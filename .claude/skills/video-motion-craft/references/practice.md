# 沒有使用者在場時，怎麼把動態練好

用在兩版草稿之間、或開工前：用尺裡最好的片段練手，把量到的差距補回轉場尺。原則和 video-draft-review 一樣：不靠感覺，靠和尺並排的數字。

## 1. 重製練習（尺裡最好的那 3 秒）

- 從尺裡挑最難的 3 秒，例如一次變形或一個轉場，用 HyperFrames 原樣重做。
- 和原片逐格並排，量蓄力、過頭、緩動、動態模糊的差距（工具在 `<tool>/scripts/measure/`）。
- 差距補進 [transition-ruler.md](transition-ruler.md) 的數字，或補進該片的 ruler.md。
- 重製只是練習，不進成片（參考不進成片）。

## 2. 自己能做的研究（不必等使用者）

- 每支片開工前：
  - 用 /watch 看 3 支以上新的頂尖作品，同類型、同題材各一；
  - 量成數字，補進參考庫；
  - 從裡面挑一個從沒用過的手法，排進這支片的一個接縫或主角拍。
- 每支片結束後：寫一段檢討（哪三件事和尺差最多、下一支怎麼補），放在該片的 REVIEW.md 最後。
